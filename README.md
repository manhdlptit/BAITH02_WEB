# Ứng dụng Thời tiết Việt Nam

## Yêu cầu

- Đã cài Node.js và npm.

## Cài đặt và chạy

Mở terminal tại thư mục dự án `weather-app`, sau đó chạy:

```bash
npm install
npm run dev
```

Mở địa chỉ được hiển thị trong terminal, thường là [http://localhost:5173](http://localhost:5173).

Để dừng máy chủ phát triển, nhấn `Ctrl+C` trong terminal.

## Build production

```bash
npm run build
```

Ứng dụng lấy dữ liệu thời tiết từ Open-Meteo, vì vậy cần kết nối Internet để tải dữ liệu.
